# Localhelp Application - Overview
LocalHelp is a web application that helps users browse medicines, add medicines to a shopping cart, place orders, and view their order history.

# Technology Stack
- Frontend: React.js
- Backend: Java Spring Boot
- Database: MySQL
- 
# Features
- User Login: Users can log in to access the application.
- Medicine Listing: Users can browse available medicines.
- Shopping Cart: Users can add medicines to their cart and manage their selections.
- Place Orders: Users can place orders for medicines in their cart.
- Order History: Users can view their previously placed orders.
- Logout: Users can securely log out of their accounts.
  
# Flow
User Login → Browse Medicines → Add to Cart → Place Order → View Order History → Logout
